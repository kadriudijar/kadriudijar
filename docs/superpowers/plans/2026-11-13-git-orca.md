# Git orca Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A nightly-redrawn pixel-art orca GIF on the `kadriudijar` profile README, driven by public GitHub activity.

**Architecture:** One script, `orca.py`: fetch (GraphQL) → pure signal functions → sprite renderer → GIF. A workflow runs it nightly and commits the GIF on change.

**Tech Stack:** Python 3.12, Pillow, GitHub GraphQL via `urllib`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-13-git-orca-design.md`

## Global Constraints

- Canvas 128×64 px, deep-water background, scaled 2× nearest-neighbour to 256×128.
- Stages: calf < 500, juvenile < 3000, adult ≥ 3000 lifetime contributions.
- Pod: one calf per 4 streak weeks, max 2.
- Behavior order: rest (≥ 3 quiet days) → spyhop (first active day of Mon–Sun week) → breach (≥ 2× previous-28-day daily average and ≥ 5) → cruise.
- Only dependency beyond the standard library: Pillow.
- Output path: `orca/orca.gif`.

## Review Focus

- Calendar days after "today" (GitHub returns the whole current week): they must be ignored, not counted as quiet.
- The in-progress Mon–Sun week with no activity yet must not end the streak.
- No languages, or a language with `color: null`: use a default grey saddle.
- A brand-new account with zero contributions: calf, cruise or rest, no crash.
- GraphQL error or missing token: exit non-zero before writing, so the old GIF stays.

### Task 1: Signals

**Files:**
- Create: `orca.py`, `test_orca.py`

**Interfaces:**
- Produces, in `orca.py` (`days` is `dict[date, int]`, `today` is the UTC day that just ended):
  - `stage(total: int) -> str` — `"calf" | "juvenile" | "adult"`
  - `weekly_streak(days, today) -> int`
  - `pod_size(streak_weeks: int) -> int`
  - `behavior(days, today) -> str` — `"rest" | "spyhop" | "breach" | "cruise"`
  - `top_color(languages: dict[str, tuple[str | None, int]]) -> str` — name → (hex color, bytes); returns `"#8a8a8a"` when none.

- [ ] **Step 1: Write tests** in `test_orca.py` (plain asserts, runnable with `python test_orca.py`):
  - `stage(499)=="calf"`, `stage(500)=="juvenile"`, `stage(2999)=="juvenile"`, `stage(3000)=="adult"`
  - `pod_size(3)==0`, `pod_size(4)==1`, `pod_size(100)==2`
  - streak: active in each of the 5 previous weeks and none yet in the current week → `5`; a fully quiet complete week in between ends it
  - days after `today` with count 0 do not affect `behavior` or `weekly_streak`
  - `behavior`: 3 quiet days ending today → `"rest"`; Monday active after quiet prior days of week (but < 3 quiet) → `"spyhop"`; today 10 with 28-day average 2 on a non-first day → `"breach"`; today 4 with average 1 → `"cruise"` (below the minimum 5)
  - `top_color({})=="#8a8a8a"`; null-color top language falls back to grey; largest bytes wins
- [ ] **Step 2: Run** `python test_orca.py` → fails (import error).
- [ ] **Step 3: Implement** the five functions.
- [ ] **Step 4: Run** `python test_orca.py` → prints `ok`.

### Task 2: Sprites and render

**Files:**
- Modify: `orca.py`

**Interfaces:**
- Consumes: Task 1 return values.
- Produces: `render(stage: str, color: str, pod: int, behavior: str) -> list[PIL.Image.Image]` (256×128 frames), `save_gif(frames, path: str) -> None`.

- [ ] **Step 1: Draw sprites** as string grids, one char per palette entry (`.` transparent, `K` black, `W` white, `S` saddle accent, `G` belly shade). One adult orca side view with 2–3 tail-stroke frames; calf/juvenile are the adult scaled down (nearest) — no separate art.
- [ ] **Step 2: Animate** per behavior: cruise = tail strokes + slow drift; rest = horizontal at surface, slow bob; spyhop = rotated upright, head above the waterline; breach = arc out of the water with splash pixels. Pod calves trail behind and below. 8–16 frames.
- [ ] **Step 3: Verify** by rendering all 4 behaviors × 3 stages to a scratch folder and looking at them.

- [ ] **Step 1: Implement `fetch`**: query `contributionYears`, then one `contributionCalendar` per year (`from`/`to` bounds); repos `ownerAffiliations: OWNER, isFork: false, privacy: PUBLIC`, languages edges with size and color. Raise on GraphQL `errors`.
